# 番外 / IF 线

一本书除正文外可以有多条「线」。不给 `blueprints / drafts / canon_*` 加列，用**章号地址空间**分线。

## 地址空间

- 正文：`1–9999`
- 线 `id` 的章：`id × 10000 + 线内序号`（序号 `1–9999`）
- 显示名：正文 `第N章`；番外 `番外·线名 k`；IF `IF·线名 第k章`
- 物理文件名由 `chapterFileName` 生成；库内仍存绝对章号

## 可见性（写稿 / 审稿 / Gate 共用 `buildCanonContext`）

| 当前章 | 可见正文 | 可见本线 | 压缩摘要 `-1` |
| --- | --- | --- | --- |
| 正文 N | `< N`（事实 `introduced_at ≤ N-1`） | 无 | 可见 |
| 番外 / IF 第 k 章 | `≤ 锚点`（锚点 0 则无） | 本线 `1…k-1` | 不可见 |
| 其它线 | 不可见 | 不可见 | — |

## 定稿写回

| 写入 | 正文 | 番外 / IF |
| --- | --- | --- |
| 时间线 / 事实 / 章摘要 | 是 | 是（本线章号） |
| 角色卡 / 剧情线 / 知识库 / 压缩摘要 / 文风 | 是 | **否** |
| 角色状态快照（`summary_snapshots`） | 定稿时存 | 读锚点章快照；无则退回当前卡 |
| 伏笔埋设 | 是 | 是（本线章号） |
| 伏笔回收 | 是 | 仅本线已埋；正史伏笔只读不收 |

## 导出

- 番外：`appendix`（默认，正文末「番外」节）/ `inline`（插在锚点章后，锚点 0 在最前）/ `separate`（每条线一个文件）
- IF：**始终** `书名·IF·线名`，可用开关排除
- 章号属于未登记线时单独成文 `书名·未登记线`，不静默丢章
- 项目配置 `project_core.extra_export_mode`，导出对话框可临时覆盖

## 取舍

- 剧情线按 `started_at` / `resolved_at` 还原窗口内是否未结：正史后来才了结的线，在锚点处仍视为进行中；锚点之后才推进的 `currentState` 不注入。开书即有（时间戳 0）的事实 / 剧情线对有正史可读的线可见，前传不可见。
- 老项目锚点前无角色快照时退回当前角色卡
- 删除线时若线内仍有章节卡或草稿，返回 `BRANCH_NOT_EMPTY`
